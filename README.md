# Taama — L'Aventure des trésors cachés de l'Afrique de l'Ouest

Jeu web 3D (three.js) autour de la Grande Mosquée de Djenné. Chapitre 1 : Djenné.

- **Jouer** : https://diakitemoussa-dot.github.io/Taama/
- Mobile : commandes tactiles personnalisables (Options › Commandes) ; qualité adaptée à l'appareil et à la connexion (`?quality=low|mid|high`, `?net=slow|medium|fast`).

## Lancer en local
```
npm install
node _serve.cjs     # http://localhost:8123
```
